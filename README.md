# 📝 ToDo App

A modern Android ToDo application built using **Kotlin** following the **MVVM Architecture**. The app helps users efficiently manage daily tasks with an intuitive interface and offline data storage.

## ✨ Features

- ✅ Add new tasks
- 📝 Edit existing tasks
- ❌ Delete tasks
- ✔️ Mark tasks as completed
- 🖼️ Attach images to tasks
- 📂 Category support
- 📅 Due date management
- 💾 Offline storage using Room Database
- 🎨 Material Design UI

## 🛠️ Tech Stack

- Kotlin
- Android SDK
- XML
- MVVM Architecture
- Room Database
- LiveData
- ViewModel
- RecyclerView
- Navigation Component
- Material Design
